# Temperature Converter Website

This project was developed as part of the Oasis Infobyte Web Development & Designing Internship Program.

The main objective of this project was to build an interactive temperature converter web application using HTML, CSS, and JavaScript.

In this project, I created a modern and responsive temperature conversion tool that allows users to convert temperature values between Celsius, Fahrenheit, and Kelvin. The application also includes input validation and absolute zero validation to prevent invalid temperature values.

I designed the interface using a modern glassmorphism UI style and added a dark/light mode feature to improve user experience.

Features implemented in this project:
- Temperature conversion between Celsius, Fahrenheit, and Kelvin
- Real-time validation for invalid inputs
- Absolute zero temperature validation
- Dark and Light mode toggle
- Responsive design for all screen sizes
- Interactive and user-friendly interface

Through this project, I learned:
- JavaScript Functions and Logic Building
- DOM Manipulation
- Input Validation Techniques
- Event Handling in JavaScript
- Responsive UI Design
- Modern Web Styling Techniques

Technologies Used:
- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

This project helped me improve my problem-solving skills and gain practical experience in building interactive web applications.
