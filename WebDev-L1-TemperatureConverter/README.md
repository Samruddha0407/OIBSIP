Temperature Converter

A modern, responsive, and interactive temperature conversion web application developed using HTML5, CSS3, and JavaScript. This project was created as part of the Oasis Infobyte Web Development & Designing Internship Program.

Project Overview

The Temperature Converter is a user-friendly web application that allows users to quickly convert temperature values between Celsius, Fahrenheit, and Kelvin.

The project focuses on implementing core front-end development concepts such as JavaScript functions, DOM manipulation, event handling, input validation, responsive design, and modern UI styling.

The application also includes absolute zero validation to prevent users from entering physically invalid temperature values.

Objectives

The main objectives of this project are:

- Build an interactive temperature conversion web application.
- Implement accurate temperature conversion formulas using JavaScript.
- Provide real-time validation for user inputs.
- Prevent temperatures below absolute zero.
- Create a modern and visually appealing user interface.
- Implement a functional Dark/Light mode.
- Make the application responsive across different screen sizes.
- Practice JavaScript DOM manipulation and event handling.

Features

 Temperature Conversion

The application supports conversion between:

- Celsius (°C)
- Fahrenheit (°F)
- Kelvin (K)

Users can select the input temperature unit and the desired output unit to perform conversions instantly.

 Real-Time Conversion

Temperature values are processed dynamically using JavaScript, providing quick conversion results without requiring a page reload.

 Input Validation

The application validates user input to prevent:

- Empty values
- Invalid numeric inputs
- Non-numeric characters
- Incorrect temperature values

 Absolute Zero Validation

The application prevents physically impossible temperatures below absolute zero.

Minimum valid temperatures are:

- Celsius: −273.15°C
- Fahrenheit: −459.67°F
- Kelvin: 0 K

This ensures that users receive meaningful and scientifically valid results.

Dark & Light Mode

A functional theme toggle allows users to switch between:

- Light Mode
- Dark Mode

The interface changes dynamically to improve usability and provide a comfortable viewing experience.

 Responsive Design

The application is designed to work across different screen sizes, including:

- Desktop
- Laptop
- Tablet
- Mobile devices

 Modern Glassmorphism UI

The interface uses a modern glassmorphism-inspired design with clean layouts, smooth visual effects, and a user-friendly interface.

Interactive Interface

Interactive elements include:

- Temperature input
- Unit selection
- Conversion result
- Theme toggle
- Validation messages
- Hover and transition effects

Temperature Conversion Formulas

Celsius to Fahrenheit

"°F = (°C × 9/5) + 32"

Fahrenheit to Celsius

"°C = (°F − 32) × 5/9"

Celsius to Kelvin

"K = °C + 273.15"

Kelvin to Celsius

"°C = K − 273.15"

Fahrenheit to Kelvin

"K = (°F − 32) × 5/9 + 273.15"

Kelvin to Fahrenheit

"°F = (K − 273.15) × 9/5 + 32"
